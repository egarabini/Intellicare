# DOCUMENTACAO — IntelliCare

Estrutura canônica de documentação do projeto IntelliCare.
Última atualização: 2026-03-08

## Estrutura

| Pasta | Pergunta que responde |
|---|---|
| `01_GOVERNANCA/` | Como o time funciona? Quais são os papéis? |
| `02_NORMAS_E_PADROES/` | Como nomeio arquivos? Como faço commit? |
| `03_ARQUITETURA/` | Como o sistema está estruturado? |
| `04_VERSOES/` | O que está planejado para a versão X? |
| `05_INFRAESTRUTURA/` | Como faço deploy? O que fazer quando dá erro? |
| `06_ANDAMENTO/` | Qual demanda está em andamento agora? |
| `07_HISTORICO/` | Como chegamos até aqui? |

## Regra de dois mundos

- **Dentro dos módulos** (`intellicare-*/docs/`): specs funcionais e técnicas de cada módulo
- **Aqui** (`DOCUMENTACAO/`): como o time trabalha, versões cross-módulo, infra, andamento, histórico

## Atalhos rápidos

- Nova demanda → `06_ANDAMENTO/DEMANDAS/`
- Especificação de versão → `04_VERSOES/`
- Problema de deploy → `05_INFRAESTRUTURA/`
- Regras de código → `02_NORMAS_E_PADROES/`
