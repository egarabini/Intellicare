## Decisões técnicas do sprint

### DEM-065 — tenant_provisioner.py
O provisionamento automático usa Alembic **programático** — não via CLI. Requer setar `search_path` antes de rodar `alembic upgrade head` para garantir que as migrations são aplicadas no schema correto do tenant.

### DEM-066 — VAPID keys
Chaves geradas com `py-vapid`, armazenadas em `.env.staging`. **Nunca rotacionar** sem truncar `push_subscriptions` primeiro — subscriptions antigas ficam inválidas silenciosamente.

### DEM-067 — Kestra Switch
Kestra 0.20 usa `io.kestra.core.tasks.flows.Switch` com field `value` (string interpolada) e `cases` (map). `if/else` não existe nativamente. `jornada_basica` foi mantida para backward compatibility — o novo default é `careplanner_jornada_com_fallback`.

Observação de CODEX: `trigger_flow()` já aceitava `flow_id` dinâmico antes desta DEM. O ajuste foi apenas trocar o default do request.
