# intellicare-core

SDK compartilhado do IntelliCare V3.

## Componentes

- `contracts`: contratos base dos modulos e schemas compartilhados.
- `config`: carregamento centralizado de configuracoes.
- `db`: helpers de sessao e provisionamento multi-tenant.
- `auth`: validacao JWT e dependencias FastAPI.
- `vector`: embeddings, busca semantica e geracao via OLLAMA.
- `module_loader`: carregamento dinamico de modulos.
