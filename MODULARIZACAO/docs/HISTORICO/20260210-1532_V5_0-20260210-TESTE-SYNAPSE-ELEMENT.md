# Teste Inicial Synapse/Element (IntelliCare)

## Objetivo

Validar o stack Matrix (Synapse + Element) antes da integracao completa com os agentes.

## Observacao sobre o compose atual

O arquivo `docker-compose-chat.yml` sobe **dois stacks de chat**:

- Rocket.Chat (Mongo)
- Matrix (Synapse + Element)

Para o modulo `intellicare-comunicacao`, o alvo e Matrix/Synapse.

## Checklist tecnico minimo

1. DNS e TLS ativos para:
`matrix.gsi.srv.br` e `element.gsi.srv.br`.
2. Traefik roteando:
`matrix.gsi.srv.br -> synapse:8008`.
3. Synapse com usuario tecnico existente (ex.: `@intellicare_bot:matrix.gsi.srv.br`).
4. Credenciais do bot validas no `.env` do modulo.

## Comandos de verificacao (no servidor Docker)

1. Subir stack:

```bash
docker compose -f docker-compose-chat.yml up -d
```

2. Ver status:

```bash
docker compose -f docker-compose-chat.yml ps
```

3. Ver logs Synapse:

```bash
docker logs -f synapse
```

4. Ver versoes Matrix (endpoint publico):

```bash
curl https://matrix.gsi.srv.br/_matrix/client/versions
```

## Teste com modulo intellicare-comunicacao

Dentro de `MODULARIZACAO/intellicare-comunicacao`:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python smoke_test_matrix.py
python smoke_test_matrix.py --room-id "!sala:matrix.gsi.srv.br" --message "Teste IntelliCare"
```

## Resultado esperado

- Login Matrix com `OK`.
- Mensagem enviada com retorno de `event_id`.
- `GET /api/v1/health` retorna `matrix: ok` quando `ENABLE_HEALTH_LOGIN_CHECK=true`.

## Riscos comuns no primeiro teste

- Usuario bot nao existe no Synapse.
- Credencial incorreta.
- Traefik sem rota para `/_matrix`.
- Certificado/TLS incompleto no dominio Matrix.
