Arquitetura LEGO

  • Cada módulo = deploy independente, API REST
  • Contratos padronizados: /health, /info
  • Comercialização individual ou ecossistema completo
  • Schemas separados: operacional e analítico
  • Zero vendor lock-in: stack 100% open-source
  • LGPD by design: pseudonimização, audit trail

Multi-Tenancy: A Evolução

  • 2 camadas: Plataforma (admin, billing) + Tenant (clínico)
  • Schema por tenant: tenant_{id} no PostgreSQL
  • Isolamento LGPD: dados clínicos nunca vazam entre tenants
  • Token Exchange: usuário multi-org seleciona organização
  • Redis com prefixo tenant:{id}: para cache isolado

Fluxo de Onboarding

  1. SuperAdmin cadastra nova empresa no intellicare-admin
  2. Admin cria schema tenant_{id} no PostgreSQL
  3. Roda migrations no schema
  4. Cria grupo no Keycloak + usuário admin
  5. Registra em platform.tenants
  6. Inicializa intellicare-gestor para o tenant
  7. Seed data: roles padrão, configs
  8. Tenant ativo e pronto para uso

TenantContext (F0)

  • JWT com claim tenant_id e tenants (array)
  • TenantContext: tenant_id, tenant_schema, user_id, roles
  • Schema isolado: tenant_{id}.tabela no PostgreSQL
  • Redis: tenant:{id}:{module}:{key}
  • Modo single-tenant: tenant_id=default funciona sem alteração
