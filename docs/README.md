# Docs — Índice Geral

Este diretório foi organizado por assunto.

## Estrutura principal

- `API_OPENAPI/`
  - catálogo de APIs, levantamentos e plano de unificação OpenAPI.
- `ARQUITETURA_E_DADOS/`
  - visão geral, estratégias de schema e especificações de separação operacional/analítico.
- `PLANOS_E_ESTRATEGIA/`
  - planos de implementação e materiais de estratégia de execução.
- `RELATORIOS_E_ANDAMENTO/`
  - relatórios de progresso, andamento e retrospectivas.
- `GOVERNANCA/`
  - índices e documentos de governança documental.
- `HISTORICO/`
  - documentos históricos e análises legadas.
- `NORMAS_E_PADROES/`
  - normas e padrões oficiais de documentação e organização.
- `SERVIDORES/`
  - configurações, guias de deploy e documentação de servidores (desenvolvimento, homologação, produção).
