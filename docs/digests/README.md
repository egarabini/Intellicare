# Digests IntelliCare

Resumo curto de ciclos, sprints ou blocos de DEMs quando o projeto acumular contexto demais
para ser recuperado apenas pelos arquivos individuais.

Uso recomendado:
- consolidar uma sprint fechada
- registrar licoes operacionais depois de incidente de staging
- resumir um conjunto grande de DEMs para handoff entre devs e agentes
