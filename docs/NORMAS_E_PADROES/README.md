# Normas e Padroes

Repositorio central de orientacoes obrigatorias de documentacao e organizacao do projeto.

## Objetivo

Concentrar regras de:
- nomenclatura de arquivos;
- organizacao de pastas;
- padroes de documentacao;
- convencoes de processo.

## Estrutura sugerida

- `PADRAO_NOMENCLATURA_DOCUMENTOS.md`
- `PADRAO_ORGANIZACAO_PASTAS.md` (futuro)
- `PADRAO_ESTRUTURA_ESPECIFICACOES.md` (futuro)
- `PADRAO_REGISTRO_EVOLUCAO.md` (futuro)

## Regra de uso

Toda nova orientacao transversal deve ser registrada nesta pasta.
