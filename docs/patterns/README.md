# Patterns IntelliCare

Catalogo de padroes de implementacao reutilizaveis extraidos de DEMs ja entregues.
Quando uma DEM estabilizar um jeito recorrente de implementar backend, frontend ou worker,
o padrao entra aqui com referencia concreta de arquivo ou demanda.

## Indice
- [Backend Modules](backend-modules.md)
- [Frontend Pages](frontend-pages.md)
- [Workers e Webhooks](workers-webhooks.md)

## Regra operacional
- Nao registrar teoria generica. Cada entrada precisa apontar para modulo, arquivo ou DEM real do IntelliCare.
- Quando um padrao quebrar, atualizar este catalogo junto com a DEM que introduziu a mudanca.
- Se o problema for recorrente e doloroso, ele deve sair daqui e ganhar uma entrada propria em `docs/gotchas/`.
