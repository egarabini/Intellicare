# FASE 1.3.B - Testes do Mapper FHIR

**Data:** 2026-02-24 12:00
**Status:** ✅ CONCLUÍDO

## Objetivo

Criar testes unitários para o CarePlanFHIRMapper sem dependência de rede.

## Implementação

### Arquivo Criado

`intellicare-geralda/tests/test_fhir_mapper.py`

### Estrutura dos Testes

#### 1. TestCarePlanFHIRMapperTo (4 testes)
- `test_to_fhir_careplan_minimal_structure` - Verifica estrutura FHIR R4 válida
- `test_to_fhir_careplan_with_conditions_and_goals` - Mapeamento de condições e metas
- `test_to_fhir_careplan_status_mapping` - Mapeamento de status (active=True→"active", False→"completed")
- `test_to_fhir_careplan_with_tasks` - Mapeamento de tarefas para atividades
- `test_to_fhir_careplan_all_categories` - Todas as 7 categorias (MEDICATION, EXERCISE, DIET, EXAM, APPOINTMENT, MONITORING, EDUCATION)

#### 2. TestCarePlanFHIRMapperFrom (4 testes)
- `test_from_fhir_careplan_minimal` - Conversão mínima FHIR → Geralda
- `test_from_fhir_careplan_parse_description` - Parse de condições e metas da descrição
- `test_from_fhir_careplan_invalid_resource_type` - Erro para resourceType inválido
- `test_from_fhir_careplan_empty_description` - Comportamento com descrição vazia

#### 3. TestRoundTrip (2 testes)
- `test_round_trip_preserves_core_fields` - Campos principais preservados (ida e volta)
- `test_round_trip_with_deactivated_plan` - Plano desativado mantém status

#### 4. TestConvenienceFunctions (2 testes)
- `test_to_fhir_careplan_function` - Função wrapper
- `test_from_fhir_careplan_function` - Função wrapper
