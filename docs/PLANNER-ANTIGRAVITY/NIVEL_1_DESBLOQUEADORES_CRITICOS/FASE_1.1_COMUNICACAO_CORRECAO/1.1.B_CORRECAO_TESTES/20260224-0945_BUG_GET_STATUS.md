# Problema Identificado: test_get_status - 2026-02-24 09:45

## Erro

```
sqlalchemy.exc.ArgumentError: Column expression, FROM clause, or other columns clause element expected, got <class 'comunicacao.channels.models.ExternalMessageLog'>.
```

## Causa Raiz

O `ExternalMessageLog` é um **Pydantic BaseModel**, não um modelo SQLAlchemy!

```python
# comunicacao/channels/models.py
class ExternalMessageLog(BaseModel):  # ← Pydantic, não SQLAlchemy!
    ...
```

Mas o `SMSDispatcher.get_status()` tenta fazer:

```python
stmt = select(ExternalMessageLog).where(...)  # ← Não funciona com Pydantic!
```

## Solução

Este é um **BUG NO CÓDIGO PRODUÇÃO**, não no teste. O dispatcher está usando SQLAlchemy com um modelo Pydantic.

### Opções:

1. **Converter ExternalMessageLog para modelo SQLAlchemy** (recomendado)
   - Alterar `BaseModel` para herdar de tabela SQLAlchemy
   - Adicionar colunas SQLAlchemy
   - Requer migração de banco

2. **Criar modelo SQLAlchemy separado**
   - Manter Pydantic para API
   - Criar modelo SQLAlchemy para DB
   - Usar mapper entre os dois

3. **Mockar todo o método get_status** (workaround rápido)
   - Retornar valor mockado
   - Não testa a lógica real

## Decisão

Por enquanto, vamos usar a **opção 3** (mockar) para finalizar a FASE 1.1.B, mas abrir issue para corrigir o bug depois.
