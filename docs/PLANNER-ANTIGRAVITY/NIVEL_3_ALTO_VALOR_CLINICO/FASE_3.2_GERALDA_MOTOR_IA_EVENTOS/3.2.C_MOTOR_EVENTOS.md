### 2. Estrutura IntelliCareEvent

```python
@dataclass
class IntelliCareEvent:
    event_id: str                    # UUID único
    event_type: str                  # ex: "care.plan_created"
    source: str                      # ex: "geralda", "oswaldo"
    patient_id: str                  # ID do paciente
    timestamp: datetime              # Quando ocorreu
    payload: dict[str, Any]          # Dados específicos
    correlation_id: Optional[str]    # Cadeia de eventos
    idempotency_key: str             # Chave única
    metadata: dict[str, Any]         # Infos extras
```

### 3. Pipeline de 7 Estágios

```
(1) Normalização   → Converte para formato IntelliCareEvent
        |
(2) Idempotência   → Verifica duplicidade (Redis)
        |
(3) Enriquecimento → Carrega dados do paciente (Model)
        |
(4) Interpretação  → Identifica contexto de jornada
        |
(5) Execução       → Aplica protocolo correspondente
        |
(6) Evidência      → Gera registro auditável
        |
(7) Persistência   → Salva no PostgreSQL
```

## Tabela journey_events (SQL)

```sql
CREATE TABLE journey_events (
    id BIGSERIAL PRIMARY KEY,
    event_id UUID UNIQUE NOT NULL,
    event_type VARCHAR(100) NOT NULL,
    source VARCHAR(50) NOT NULL,
    patient_id VARCHAR(64) NOT NULL,
    timestamp TIMESTAMPTZ NOT NULL,
    payload JSONB NOT NULL DEFAULT '{}',
    correlation_id UUID,
    idempotency_key VARCHAR(128) UNIQUE NOT NULL,
    metadata JSONB DEFAULT '{}',
    
    processing_status VARCHAR(20) DEFAULT 'received',
    context_activated VARCHAR(20),
    protocol_executed VARCHAR(50),
    actions_taken JSONB DEFAULT '[]',
    error_message TEXT,
    
    processed_at TIMESTAMPTZ,
    processing_duration_ms INTEGER,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_events_patient ON journey_events(patient_id);
CREATE INDEX idx_events_type ON journey_events(event_type);
CREATE INDEX idx_events_timestamp ON journey_events(timestamp);
CREATE INDEX idx_events_correlation ON journey_events(correlation_id);
CREATE INDEX idx_events_status ON journey_events(processing_status);
```
