# 3.2.A - Integração Ollama (EF-003)

**Data de início:** 2026-02-24 12:45
**Status:** 🔄 EM ANDAMENTO

## Objetivo

Dotar Geralda de capacidade de raciocínio em linguagem natural usando LLM local (Ollama).

## Arquivos Criados

### Core
- `geralda/ai/__init__.py` - Package exports
- `geralda/ai/llm_provider.py` - Factory para LLM (Ollama/OpenAI/None)
- `geralda/ai/geralda_agent.py` - Agente conversacional

### Prompts
- `geralda/ai/prompts/__init__.py` - Package exports
- `geralda/ai/prompts/system_prompt.py` - Identidade e regras da Geralda
- `geralda/ai/prompts/care_prompts.py` - Prompts para operações de cuidado

### Tools LangChain
- `geralda/ai/tools/care_tools.py` - 5 tools para operações de plano de cuidado

### API
- `geralda/api/chat_routes.py` - Endpoints `/api/v1/chat` e `/api/v1/chat/create-plan`
- `geralda/api/app.py` - Atualizado para incluir rotas de chat

## Funcionalidades Implementadas

### LLMProvider
- Factory pattern para múltiplos providers
- Suporte: Ollama (primário), OpenAI (fallback), None (sem IA)
- Graceful degradation: fallback automático se provider falhar

### GeraldaAgent
- Processamento de mensagens com LLM
- Sistema de prompts com identidade da Geralda
- Diretrizes de segurança emergencial
- Respostas de fallback sem IA
- 5 tools LangChain integradas:
  1. create_care_plan - Criar plano
  2. get_care_plan - Buscar plano
  3. add_care_task - Adicionar tarefa
  4. complete_task - Completar tarefa
  5. get_adherence - Calcular adesão

### System Prompt
- Identidade: Geralda Lopes da Silva
- 7 regras absolutas (não diagnosticar, não alterar prescrições, etc.)
- Capacidades definidas
- Diretrizes de emergência
- Linha de guarda segura

### Prompts de Cuidado
- CREATE_CARE_PLAN_PROMPT - Criar plano personalizado
- EXPLAIN_TASK_PROMPT - Explicar tarefa em linguagem simples
- ADHERENCE_ANALYSIS_PROMPT - Analisar adesão
- MOTIVATIONAL_MESSAGE_PROMPT - Mensagem motivacional

### Endpoints API
- `POST /api/v1/chat` - Chat com a Geralda
- `POST /api/v1/chat/create-plan` - Criar plano assistido por IA

## Configuração

Variáveis de ambiente (adicionar ao `.env`):
```env
# LLM Provider
INTELLICARE_LLM_PROVIDER=ollama  # ollama, openai, none
INTELLICARE_LLM_TEMPERATURE=0.3
INTELLICARE_OLLAMA_URL=http://localhost:11434
INTELLICARE_OLLAMA_MODEL=mistral:7b
INTELLICARE_OLLAMA_CONTEXT_SIZE=8192
INTELLICARE_OLLAMA_TIMEOUT=60
```
