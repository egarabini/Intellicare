## Entregas

### 1. LLMProvider ✅

**Arquivo:** `geralda/ai/llm_provider.py`

**Classe `LLMProvider`:**
```python
class LLMProvider:
    @staticmethod
    def create(
        provider: str = "none",  # "ollama", "openai", "none"
        ollama_url: str = "http://localhost:11434",
        ollama_model: str = "mistral:7b",
        temperature: float = 0.3,
        context_size: int = 8192,
        timeout: int = 60,
        openai_api_key: Optional[str] = None,
        openai_model: str = "gpt-4o-mini",
    ) -> Optional[BaseChatModel]

    @staticmethod
    async def check_availability(llm: Optional[BaseChatModel]) -> bool
```

**Características:**
- Factory pattern para múltiplos providers
- Suporte: Ollama (primário), OpenAI (fallback), None (sem IA)
- Graceful degradation: fallback automático se provider falhar
- Logging de erros para debug

### 2. GeraldaAgent ✅

**Arquivo:** `geralda/ai/geralda_agent.py`

**Classe `GeraldaAgent`:**
```python
class GeraldaAgent:
    def __init__(
        self,
        llm: Optional[BaseChatModel],
        tools: list[BaseTool],
        session_factory: async_sessionmaker[AsyncSession],
    )

    async def chat(
        message: str,
        patient_id: str,
        patient_context: str = "",
        history: Optional[list[dict]] = None,
        role: str = "patient",
    ) -> dict[str, Any]

    async def create_care_plan(
        patient_id: str,
        patient_name: str,
        conditions: list,
        goals: list,
    ) -> dict[str, Any]
```

**Características:**
- Processamento de mensagens com LLM
- Sistema de prompts com identidade da Geralda
- Diretrizes de segurança emergencial
- Respostas de fallback sem IA (modo sem LLM disponível)
- Integração com 5 tools LangChain

### 3. System Prompt da Geralda ✅

**Arquivo:** `geralda/ai/prompts/system_prompt.py`

**Componentes:**
- `GERALDA_SYSTEM_PROMPT` - Identidade e regras da Geralda
- `build_system_prompt()` - Constrói prompt com contexto do paciente
- `EMERGENCY_PROMPT` - Diretrizes de emergência (pronto-socorro)
- `SAFETY_GUIDELINES` - Linha de guarda segura

**Regras Absolutas:**
1. NUNCA faça diagnósticos
2. NUNCA altere prescrições
3. NUNCA invente dados clínicos
4. SEMPRE sugira consulta profissional
5. SEMPRE use linguagem simples e acolhedora
6. SEMPRE considere o nível de letramento
7. Em emergência, oriente ir ao pronto-socorro IMEDIATAMENTE

```python
class ChatRequest(BaseModel):
    message: str
    patient_id: str
    session_id: Optional[str] = None
    role: str = "patient"  # "patient" ou "professional"
    patient_context: Optional[str] = None
    history: Optional[list[dict]] = None

class ChatResponse(BaseModel):
    success: bool
    response: str
    actions_taken: list[dict]
    patient_id: str
    session_id: Optional[str]
    mode: str  # "ai" ou "fallback"
```
